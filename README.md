🎀 AI Study Assistant – Notes Summarizer and Quiz Generator

📚 Project Overview

AI Study Assistant is an AI-powered web application developed using Python and Streamlit. It helps students understand and prepare study materials more easily by using Generative AI.

Users can upload PDF study materials, generate summaries, understand difficult topics, create questions, and practice interactive quizzes.

✨ Features

* PDF Upload: Upload study material in PDF format.
* Notes Summarizer: Automatically generates summaries from uploaded PDFs.
* Topic Explanation: Explains difficult topics in simple English.
* Question Generator: Generates MCQs, short-answer and long-answer questions.
* Practice Quiz: Provides interactive quizzes with scores, correct answers and explanations.
* User-Friendly Interface: Attractive pink-themed interface.

🛠️ Technologies Used

* Python
* Streamlit
* Groq API
* Generative AI
* PyPDF
* Python-dotenv

⚙️ Installation and Setup

1. Clone the repository:
    git clone https://github.com/chinmayi-rayarao/AI-STUDY-ASSISTANT.git
2. Navigate to the project folder:
    cd AI-STUDY-ASSISTANT
3. Install the required packages:
    pip install -r requirements.txt
4. Create a .env file and add your Groq API key:
    GROQ_API_KEY=your_groq_api_key
5. Run the application:
    streamlit run app.py
